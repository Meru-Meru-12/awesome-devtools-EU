# awesome-devtools-Poland
Curated list of developer-first tools orignally made in Poland.

Some tools listed here may have changed their headquarters locations.

# Artificial Intelligence
- [Bielik.ai](https://bielik.ai/) : Open Polish large language models from the SpeakLeash Foundation, released on Hugging Face under Apache 2.0. #oss #selfhosted
- [Infermedica API](https://developer.infermedica.com/) : REST API for symptom checking, triage and preliminary diagnosis, built on a medical inference engine. #cloud
- [Ragbits](https://ragbits.deepsense.ai/) : Python framework from deepsense.ai for building GenAI applications, with modules for RAG, agents, evaluation and guardrails. #oss #selfhosted

# CMS
- [CKEditor](https://ckeditor.com/) : Rich text editor framework with real-time collaboration, plugins, and integrations for React, Angular and Vue. #oss #selfhosted #cloud

# Deployment Hosting
- [Buddy.Works](https://buddy.works/) : The agentic cloud for developers, with pipelines that build, test and deploy code, isolated Ubuntu sandboxes for AI agents, and versioned artifacts. #cloud
- [CloudFerro](https://cloudferro.com/) : OpenStack-based public cloud with regions in Poland and Germany, including the CREODIAS platform for Earth observation data. #cloud
- [Oktawave](https://www.oktawave.com/) : Public cloud with compute, storage and Kubernetes. #cloud
- [Spacelift](https://spacelift.io/) : Infrastructure as code orchestration platform for OpenTofu, Terraform, Pulumi, Ansible and Kubernetes workflows. #cloud #selfhosted

# Documentation
- [Dataedo](https://dataedo.com/) : Data catalog for documenting databases, with a business glossary, data lineage and data quality checks. #selfhosted #cloud

# E-commerce

- [Sylius](https://sylius.com/) : Headless e-commerce framework built on Symfony. #oss #selfhosted
